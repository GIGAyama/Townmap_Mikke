# スプレッドシートのコピーで配る（作者向けの手順）

このアプリは、記録を入れるスプレッドシートにスクリプトが束ねられた状態
（コンテナバインド）で動きます。**配り方はこれ 1 つだけ**です。

コピーで配ると、先生の手数が **7 ファイル貼り付け → デプロイ** から
**コピー → メニューを 1 回押す → デプロイ** に減ります。

この文書は、そのテンプレートを作る手順です。

> **この作業は、Google アカウントを持つ人にしかできません。**
> リポジトリの側からは用意できないので、ここに手順だけ置いてあります。

---

## 1. テンプレートを作る

1. 新しいスプレッドシートを作り、名前を **「みっけ！ 学級データ」** にする。
   （コピーすると「みっけ！ 学級データ のコピー」になります。先生が名前を変えても構いません。）
2. シートは作らなくてよい。**メニューの「はじめの設定」を押したときに
   `ensureSheet_()` が必要なシートを全部作ります。**
   先に作るなら、見出し行は `Db.gs` の `TABLES` と同じにすること。
3. 「拡張機能」＞「Apps Script」を開く。
4. 既定の `コード.gs` の中身を消し、リポジトリの `Main.gs` を貼り付ける。
   ファイル名は `コード` のままでよい（`.gs` の名前は動作に関係しません）。
5. 「＋」＞「スクリプト」で残りを作り、それぞれ中身を貼り付ける
   （`Db.gs` / `Schema.gs` / `Tenant.gs` / `Bound.gs` / `Gemini.gs`）。

6. 「＋」＞「HTML」で `App` を作り、リポジトリの `App.html` を貼り付ける。
7. **マニフェストを差し替える。**「プロジェクトの設定」で
   「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れ、
   リポジトリの **`appsscript.json`** の中身を貼り付ける。

   ```json
   "webapp": { "executeAs": "USER_DEPLOYING", "access": "DOMAIN" }
   ```

   **ここを間違えると、配った全員が壊れます。**
   - `executeAs` が `USER_ACCESSING` だと、児童がスプレッドシートへのアクセス権を
     持っていないので、開いた瞬間にエラーになります。
   - `access` が `ANYONE` だと `Session.getActiveUser().getEmail()` が空になり、
     **先生も含めて誰も入れません**（`Bound.gs` が `BOUND_NO_IDENTITY` で止めます）。

8. いったん保存する。**デプロイはしない**（デプロイはコピーには付いてこないので、
   ここで作っても意味がありません）。

## 2. 中身を空にしておく

**テンプレートに残っているものは、コピーした全員に配られます。**

- 試しに立てたピン・チャット・名簿・画像を消す
- **`Settings` シートの `ownerEmail` を必ず消す。**
  残っていると、コピーした先生ではなく**あなたが全学級の先生**になります。
  `geminiApiKey` も同じく消すこと（残すと、あなたの課金キーが全学級で使われます）。
- スクリプトのプロパティが空であることを確認する
  （「プロジェクトの設定」＞「スクリプト プロパティ」）。このアプリは 1 つも読みません。

> スクリプトのプロパティは**コピーされません**が、`Settings` シートは
> **そのままコピーされます**。消し忘れがいちばん危ないのはこちらです。

## 3. 共有の設定

1. スプレッドシートの「共有」を開く。
2. 一般的なアクセスを **「リンクを知っている全員」＋「閲覧者」** にする。
   - **「編集者」にしないこと。** 編集者にすると、コピーせずに直接書き込めてしまいます。
3. リンクをコピーする。次の形になっているはずです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/edit?usp=sharing
   ```

4. 末尾を **`/copy`** に置きかえたものが、配るリンクです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/copy
   ```

   これを開くと「コピーを作成」のダイアログがすぐ出ます。

## 4. リンクを貼ってある場所（2026-08-25 に設定済み）

配っているリンクは 1 つです。

```
https://docs.google.com/spreadsheets/d/1ILZ6tGu-8BFl9u8n54rD7i729QHcwObVxPYvzr2Ne2I/copy
```

| ファイル | 場所 |
|---|---|
| `docs/index.html` | 「入れかた」の「スプレッドシートをコピーして始める」ボタン |
| `README.md` | 「入れかた」＞「1. スプレッドシートをコピーする」 |
| `MANUAL.md` | 「2. はじめかた」＞「ステップ 1 — コピーする」 |
| `docs/note/mikke-note-article.md` | **未反映**。記事の「導入手順」は前の配り方（共通 URL・クラスコード）のままで、載っているスクリーンショットも廃止した画面のものです。リンクだけ差し替えても筋が通らないので、記事ごと書き直しが要ります（note-article スキル＋実機のスクリーンショット） |

**テンプレートを作り直して ID が変わるときは、この表のすべてを差し替えてください。**

## 5. 入れたあとに確かめること

**この環境では GAS を実行できないため、以下は実機で 1 回だけ見てください。**

1. **別のアカウント**（できれば学校のアカウント）でコピーリンクを開き、コピーが作れるか。
   - **学校のドメインが「外部のファイルのコピー」を禁じていると、ここで止まります。**
     止まる場合は、貼り付けの手順（README）を案内し続けてください。
2. コピーしたファイルを開き、上のメニューに **「みっけ！」** が出るか。
   出たら「はじめの設定（先生として登録）」を押す。
   - 「先生として登録しました: <自分のメール>」と出れば成功。
   - `Settings` シートに `ownerEmail` が入っていることを目で確認する。
3. デプロイし（自分／同一ドメインの全員）、その URL を**先生自身**で開いて
   教師用コンソールが出るか。
4. **別の児童アカウント**で同じ URL を開き、
   - 参加の申請ができるか
   - 承認するまで地図が見えないか
   - 承認したら見えるようになるか
   - **先生用のボタンが出ていないか**（出ていたら `ownerEmail` の消し忘れを疑う）
5. 1 つピンを立て、**コピーしたそのファイル**の `Pins_ピン` シートに行が増えるか。
6. 「学級の管理」タブ ＞「シートを点検する」で「シートの作りは想定どおりです」と出るか。
7. わざと `Pins_ピン` の 2 列目に空の列を挿し、ピンを 1 つ立てて、
   **値が正しい列に入る**ことを見る（列を足しても壊れないことの実機確認）。
   確認したら列を消す。

## 5.5. 自動反映（GitHub Actions）について

`main` にマージすると `deploy.yml` が **このコンテナバインドのプロジェクトへ**
`clasp push` し、既存のデプロイを新しいバージョンに差し替えます
（宛先は `GAS_SCRIPT_ID` / `GAS_DEPLOYMENT_ID` のシークレットで決まります）。

- **`appsscript.json` も一緒に上書きされます。** リポジトリの `appsscript.json` は
  コンテナバインド版の設定（自分として実行 / 同一ドメインの全員）です。
  GAS エディタ側でマニフェストを手で変えても、次の反映で戻ります。
- **配ったテンプレートのコピーには、この自動反映は届きません。** 先生の手元に
  あるのは独立したプロジェクトです。直しを届けるにはテンプレートを作り直して
  配り直すか、先生に貼り直しをお願いすることになります。

## 6. 前の配り方で使っていた学級について

**2026-08-25 に、共通デプロイ版（クラスコード付きの共通 URL）と、貼り付けで入れた
旧バインド型（`Users_名簿` シート）を廃止しました。**

記録は消えていません。クラス DB のスプレッドシートは先生のドライブにそのまま残っています。
移すときは、そのスプレッドシートの「拡張機能 ＞ Apps Script」に上の 4〜7 を行い、
「はじめの設定」を押してからデプロイしてください。`Members` シートの名簿はそのまま使えます。
