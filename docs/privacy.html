3. 配信のしくみと保存先について

Townmap_Mikke は Google Apps Script のウェブアプリとして動きます。画面は Google のサーバー（script.google.com）から配信され、入力されたデータは導入した学校・先生ご自身の Google スプレッドシートや Google ドライブに保存されます。

制作者が独自に運用するデータベースやアプリケーションサーバーはありません。そのため、利用者が入力したデータが制作者の手元に集まることはありません。

4. Google API を利用する場合の取り扱い

Townmap_Mikke が Google アカウントへのログインを求める場合、その目的はアプリの機能を提供することに限られます。

  • アクセスを求める範囲（スコープ）は、機能の実現に必要な最小限にとどめます。
  • 取得した情報は、利用者の画面表示と、利用者ご自身のファイルへの読み書きのためだけに使用します。
  • 広告目的での利用、第三者への販売・提供、および人間による内容の閲覧は行いません。
  • アクセス権はいつでも Google アカウントの「サードパーティによるアクセス」 から取り消すことができます。

Google ユーザーデータの取り扱いは、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。

5. 生成AI（Google Gemini API）への送信について

本アプリの一部の機能は、Google が提供する生成AI「Gemini API」を利用します。この機能を使ったときだけ、以下の内容が Google のサーバーへ送信されます。

送信するもの児童が地図に付けたピンの見出しとメモ、学習中の発言
送信しないもの児童の表示名（送信前に「対象児童」「児童A」という仮名に置き換えています）、メールアドレス・電話番号・郵便番号（自動でマスクします）、児童が撮影した写真
送信先Google LLC（アメリカ合衆国）／ generativelanguage.googleapis.com
API キーの置き場所先生が用意した API キーを Apps Script のプロパティ（サーバー側）に保存します。キーがブラウザに送られることはありません。

API キーは、課金を有効にした（有料ティアの）ものをお使いください。無料ティアのキーでは、送信した内容が Google のモデル改善（機械学習）に使われる場合があります。有料ティアでは、送信した内容がモデルの学習に使われることはありません。くわしくは Gemini API の追加利用規約 をご確認ください。

生成AIの機能を使わなければ、これらの送信は発生しません。

6. Cookie・ローカルストレージ

Townmap_Mikke は、設定の保存や作業中データの一時保持のために、ブラウザのローカルストレージ等を使用することがあります。 これらは利用者の端末内にのみ保存され、ブラウザの設定から削除できます。 広告や行動追跡を目的とした Cookie は使用していません。

7. 第三者提供・外国への送信について

法令に基づく場合を除き、制作者が利用者の情報を第三者に販売・提供することはありません。

ただし、生成AIの機能を利用した場合、前掲のとおりアメリカ合衆国にある Google LLC へデータが送信されます。これは個人情報保護法にいう「外国にある第三者への提供」に当たる場合があります。学校でお使いになる場合は、設置者（教育委員会等）の定めに従い、必要な手続を取ったうえでご利用ください。

8. データの保存期間

本アプリは、利用者が自分で削除するまでデータを保持します。制作者が保存期間を一方的に定めることはありません。

  • 端末のブラウザ内（ローカルストレージ等）に保存されたデータは、利用者が削除するまで残ります。
  • Google スプレッドシートやドライブに保存されたデータは、そのファイルの所有者（先生・学校）が管理します。学年の終わりなど区切りのタイミングで、不要になったデータを削除する運用をおすすめします。
  • 生成AIへ送信した内容は、応答を受け取った時点で本アプリの中には残りません。Google 側での取り扱いは Google の定めによります。

9. データの削除

  • ブラウザ内に保存されたデータは、ブラウザの「閲覧データの削除」またはアプリ内の該当機能から削除できます。
  • Google ドライブ／スプレッドシートに保存されたデータは、利用者ご自身が Google ドライブ上で削除できます。
  • アプリへのアクセス権の取り消しは、前掲の Google アカウント設定から行えます。
