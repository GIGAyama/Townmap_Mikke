# 更新ログの書式

`docs/CHANGELOG.md` に書く。置き場と名前は決め打ち。
3 つの道具（`sync-updates.mjs` / `build-articles.mjs` / `build-manuals.mjs`）が
同じ道を叩くので、名前を変えると全部が黙って見つけられなくなる。

## 形

```md
# 更新の記録

このアプリの変わったところです。

## 2026-08-23
- 写真の上限をなくしました
- 音が出ない端末があったのを直しました

## 2026-06-01
- はじめて公開しました
```

- **日付の見出しは `## YYYY-MM-DD`。** うしろに文字を足してよい（`## 2026-08-23 夏休み明け`）が、
  出るのは日付だけ
- **項目は `- ` か `* ` で始める。** 入れ子にしない（入れ子も親と並べて拾われる）
- 最初の日付見出しより前は前書きとして読み飛ばされる。`#` の題や説明を置いてよい
- コード枠（``` ）の中は拾わない
- 順番は気にしなくてよい（機械が新しい順に並べ直す）が、人が読むので新しい順に書く

## 読み手は誰か

**使う先生と子ども。** 開発者ではない。

その 1 行を読む人は、アプリの中身を知らない。知りたいのは
「前より何ができるようになったか」「困っていたことが直ったか」だけ。

## 書くもの・書かないもの

| リポジトリでやったこと | `docs/CHANGELOG.md` に書くこと |
| --- | --- |
| `fix: localStorage の上限を撤廃` | 写真の枚数の上限をなくしました |
| `fix: iOS Safari の AudioContext を unlock` | iPad で音が出ないことがあったのを直しました |
| `chore(gate): タップ領域の検査を入れる` | ボタンを大きくして、低学年でも押しまちがえないようにしました |
| `fix(a11y): aria-label を足す` | 読み上げソフトで、どのボタンかが分かるようにしました |
| `feat: ドラッグ&ドロップで並べ替え` | 記事の並べかえを、指でつまんで動かせるようにしました |
| `chore(sw): 版を刻む` | **書かない**（使う人から見て何も変わっていない） |
| `chore(standards): Sync with latest standards` | **書かない**（42 本すべてに同じ日付で入る） |
| `refactor: build-sw.mjs を正本に合わせる` | **書かない**（画面が 1 ドットも変わらない） |
| `docs: README を直す` | **書かない** |

### 書かないものの見分け方

**その 1 行を読んだ先生が、アプリを開いて確かめられるか。**
確かめられないなら書かない。

とくに次は書かない。

- 正本配布・品質ゲート・Service Worker・キャッシュ・ビルド・CI の話
- 画面が変わらない内部の作り直し
- 「軽くしました」「速くしました」のうち、体感できないもの

### 使わない言葉

読み手が開発者ではないので、次の語はそのまま出さない。

`Service Worker` / `SW` / `キャッシュ` / `リポジトリ` / `デプロイ` / `リファクタ` /
`API` / `ビルド` / `コミット` / `PR` / `lint` / `CI` / `localStorage` / `正本` / `ゲート`

⚠️ ただし**言い換えられるなら書く**。「キャッシュを直した」は書かないが、
「前に開いた内容が古いまま出ることがあったのを直しました」なら、使う人に届く。

## 文の形

- 「〜しました」「〜できるようになりました」「〜を直しました」で言い切る
- **1 項目 1 変更。** 2 つ直したら 2 行に分ける
- 長さは **12〜45 字**が目安。トップページの狭い列で 2 行に収まる
- 体言止め（「写真の上限の撤廃」）にしない。何が起きたのか分かりにくい

## 最初の 1 本

まだ何も無いアプリでは、公開した日から始める。

```md
## 2026-06-01
- はじめて公開しました
```

## どこに何件出るか

書いたものが全部出るわけではない。**上限で切られたものは黙って落ちる**
（切った先に一覧ページが無いので「ほか N 件」も出ない）。大事なものを先に書く。

| 出る先 | 何件 |
| --- | --- |
| `giga-school.com`（トップの「更新したこと」） | 全アプリ横断。新しい **4 日付** ・全体 **12 項目** ・1 アプリ 1 日 **3 項目**まで |
| `/apps/<slug>/`（紹介ページ） | 直近 **3 日付** |
| `/apps/<slug>/manual/`（使い方マニュアル） | 直近 **3 日付** |

中身の無い日付（見出しだけ書いて項目を忘れた）は、**そのかたまりごと出ない**。

## 出す前に

```bash
node .claude/skills/giga-changelog/scripts/lint-changelog.mjs docs/CHANGELOG.md
```

⚠️ 落とすのは「機械が拾えなくなるもの」だけ。言い回しは `warn` で言うだけで止めない。
検査で書き方の好みを強制すると、書き手がこの検査を通さなくなる。
