# マニュアルの書式

## 読み手を決める

最初に決める。ここを決めないまま書くと、子どもには難しく先生には回りくどい、
どちらにも届かない文章になる。

決め方は `data/apps.json` の `grades`（対象学年）を見る。

| grades | 読み手 | 書き方 |
| --- | --- | --- |
| 学年が入っている（例 `[1,2,3]`） | **子ども** | その学年までに習う漢字。習っていない字にはルビ |
| `[]`（児童が使うものではない） | **先生** | ふつうの漢字。ルビは振らない |
| 項目そのものが無い | まだ決めていない。**先生**として書き、決まったら直す |

子ども向けのとき、ルビは Markdown の中に HTML でそのまま書く。

```
<ruby>設定<rt>せってい</rt></ruby>のボタンを おします。
```

⚠️ ルビは「難しい字」ではなく「その学年までに習っていない字」に振る。
3 年生向けなら 4 年生以上の配当漢字すべてに振る。読めない字が 1 つあると、
そこで読むのをやめてしまう。

## 見出しの並び

**変えない。** 目次と検索の索引が、この並びを前提に作られる。
`##` はこの 5 つだけ。増やしたいものは `###` にする。

```
# <アプリ名> の つかいかた

## はじめに        何ができるアプリか。だれが使うか。どこを開くか
## さいしょに      開いてから最初の 1 回にやること
## 画面の見かた    全体の写真 1 枚と、どこに何があるか
## できること      機能をひとつずつ。### で 1 機能 1 節
## こまったとき    よくある詰まりと、その場での直しかた
```

### ## はじめに

3 段落まで。何ができるアプリで、だれが使うもので、どこを開けば始まるか。
最初の一段落がそのまま検索結果とページの説明文になる（110 字で切られる）ので、
その一文だけで何のアプリか伝わるようにする。

### ## さいしょに

**開いた人が最初の 1 回だけやること。** ログイン、初期設定、
アプリとして入れておく手順、権限の許可。番号つきで書く。
やることが多いときは `###` で分ける。

何も要らないアプリでは「準備は要りません。開いたらすぐ使えます。」の
一行でよい。節ごと消さない。**無いことが分かるのも情報である。**

### ## 画面の見かた

全体の画面写真を 1 枚置き、どこに何があるかを書く。
写真の中の場所は「左上の」「画面の下の」のように、見て探せる言葉で指す。
座標や CSS の名前で書かない。

### ## できること

**このマニュアルの本体。** 数えた機能を、ひとつ残らず `###` で並べる。

- 節の名前は、**画面に出ているボタンやタブの言葉そのまま**にする。
  読み手は画面の言葉で探す。言い換えると見つからない
- 1 つの節は「何ができるか」の 1 文から始め、そのあとに番号つきの手順
- 手順は、押すものと、そのあと起きることを対にして書く

```
### 週案を印刷する

1 週間ぶんの週案を、A4 の紙に出せます。

1. 画面の上の「印刷」タブを おします。
2. 「今週」か「来週」を えらびます。
3. 「印刷する」を おすと、印刷の画面が ひらきます。
```

- 押しても戻せないこと（消す、送る、上書きする）は、その手順の中で言う。
  節の終わりにまとめて書くと、読み手はもう押している

### ## こまったとき

`###` に症状を、その言葉で書く。読み手は画面に出ている文字で探すので、
エラーの文言が出るものは、**その文言をそのまま見出しにする**。

```
### 「インターネットにつながっていません」と出る
```

原因の説明より先に、直しかたを書く。

## 書かないもの

- **「学校で使うときは」の節。** 許可するアドレス・アカウントの要否・
  記録の置き場は機械が `data/apps.json` から足す。手で書くと
  `giga-school.com/filtering/` と食い違う
- **「変わったこと」の節。** `docs/CHANGELOG.md` から機械が足す
- **連絡先。** ページの下に、サイト共通の問い合わせ先が出る
- **なぜ作ったか。** それは紹介記事の仕事

## 文体

- 短く言い切る。1 文 60 字まで
- 「〜することができます」ではなく「〜できます」
- 手順の中の主語は読み手。「システムが保存します」ではなく「保存されます」
- ボタン・タブ・メニューの文字は「」で囲み、画面に出ている言葉のまま
- 太字（`**`）を使わない。強調は「」で足りる
- 表・水平線・絵文字を使わない。組み立てが扱わない
- 分量の目安は 2,000〜8,000 字、画面写真 10〜30 枚。目安であって上限ではない。
  機能が多いアプリで削ると、削った機能が「無いもの」になる
